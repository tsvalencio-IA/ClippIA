Política de Privacidade — ClippIA Econoroeste

O ClippIA Econoroeste é um sistema de clipagem, análise de notícias, organização de relatórios e apoio à comunicação institucional.

Dados coletados

O sistema pode armazenar relatórios de clipagem, fontes, links, imagens públicas encontradas, resumos, recomendações, textos sugeridos para postagem, categorias e avaliações de risco.

Uso dos dados

Os dados são usados para organizar, revisar e consultar clipagens relacionadas à comunicação institucional e monitoramento de mídia.

Armazenamento

As informações podem ser armazenadas no Firebase Realtime Database do responsável pelo sistema.

Serviços técnicos utilizados

O sistema pode usar serviços como Firebase, Vercel, GitHub e ChatGPT Actions para funcionamento técnico.

Compartilhamento

O sistema não vende dados. O compartilhamento ocorre apenas quando necessário para execução técnica dos serviços usados pelo sistema.
