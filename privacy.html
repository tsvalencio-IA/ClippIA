Política de Privacidade — ClippIA Econoroeste

O ClippIA Econoroeste é um sistema de clipagem, análise de notícias e organização de relatórios.

Dados coletados

O sistema pode armazenar relatórios de clipagem, fontes, links, imagens públicas encontradas, resumos, recomendações e textos sugeridos para postagem.

Uso dos dados

Os dados são usados apenas para organizar, revisar e consultar clipagens relacionadas à comunicação institucional e monitoramento de mídia.

Armazenamento

As informações são armazenadas no Firebase Realtime Database do responsável pelo sistema.

Compartilhamento

O sistema não vende dados e não compartilha informações com terceiros, exceto serviços técnicos necessários para funcionamento, como Firebase, Vercel e ChatGPT Actions.
